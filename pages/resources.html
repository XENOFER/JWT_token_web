Specifications & standards

Go to the source. These RFCs define JWT and the cryptography around it.

RFC · Core

RFC 7519 — JWT

The JSON Web Token specification itself: structure, claims, and processing rules.

datatracker.ietf.org RFC · Must-read

RFC 8725 — JWT BCP

Best Current Practices. Concise, authoritative guidance on avoiding the common pitfalls.

datatracker.ietf.org RFC · Signatures

RFC 7515 — JWS

JSON Web Signature — how the signing and verification that JWT relies on actually work.

datatracker.ietf.org RFC · Algorithms

RFC 7518 — JWA

JSON Web Algorithms: the registry behind HS256, RS256, ES256 and friends.

RFC 7517 — JWK

JSON Web Key: how public keys are represented and published in key sets.
